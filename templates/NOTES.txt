📝 Getting Started

1. Create an Atelier resource to configure Sartor:

   kubectl apply -f - <<EOF
   apiVersion: autoscaling.sartorproj.io/v1alpha1
   kind: Atelier
   metadata:
     name: default
   spec:
     prometheus:
       url: http://prometheus.monitoring:9090
     gitProvider:
       type: github
       secretRef:
         name: github-token
         namespace: {{ include "sartor.namespace" . }}
   EOF

2. Create a FitProfile for your optimization strategy:

   kubectl apply -f - <<EOF
   apiVersion: autoscaling.sartorproj.io/v1alpha1
   kind: FitProfile
   metadata:
     name: balanced
     namespace: default
   spec:
     strategy: percentile
     displayName: Balanced
     parameters:
       percentile: 95
       requestsBufferPercent: 15
       limitsBufferPercent: 25
   EOF

3. Create a Tailoring to optimize a workload:

   kubectl apply -f - <<EOF
   apiVersion: autoscaling.sartorproj.io/v1alpha1
   kind: Tailoring
   metadata:
     name: my-app
     namespace: default
   spec:
     target:
       kind: Deployment
       name: my-app
     fitProfileRef:
       name: balanced
     writeBack:
       type: raw
       repository: github.com/myorg/myrepo
       path: k8s/deployment.yaml
   EOF

For more information, visit: https://github.com/sartorproj/sartor
